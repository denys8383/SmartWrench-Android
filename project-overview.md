# SmartWrench - Огляд проєкту
**Проблема:** Водіям важко розшифровувати коди помилок OBD2 та розуміти їхню критичність.
**Користувач:** Власники авто, які самостійно діагностують машини (DIY-механіки).
**Основний сценарій:** Користувач вводить код помилки та пробіг -> Мобільний додаток відправляє запит -> Backend аналізує код через AI-компонент -> Додаток показує рівень небезпеки та рекомендацію.
**Межі MVP:** Працюємо лише з ручним вводом кодів (без підключення до Bluetooth сканера) для бензинових двигунів 2.0L.
