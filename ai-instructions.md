# Правила для Coding Agent
1. Перед змінами прочитати директорію `docs/`.
2. Спочатку пояснити поточну реалізацію та запропонувати план[cite: 15].
3. Перерахувати файли, які потрібно змінити[cite: 15].
4. Не переписувати весь проєкт, змінювати лише необхідне для задачі[cite: 15].
5. Не змінювати API-контракт без оновлення `api-contract.md`[cite: 15].
6. Не додавати нових залежностей без обґрунтування[cite: 15].
7. Не генерувати реальні персональні чи приватні дані.
