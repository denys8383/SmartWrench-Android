# AI Компонент
**Призначення:** Класифікація помилок та генерація порад.
**Формат:** Приймає `dtc_code` (str) та `mileage_km` (int). Повертає словник (severity, recommendation).
**Обмеження:** Це MVP без реальної нейромережі. Використовуються жорсткі правила (if/else).
**Fallback:** Якщо код невідомий, повертається базовий статус "Низько" з порадою звернутися до документації.
