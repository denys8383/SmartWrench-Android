# Тестування мобільного застосунку SmartWrench (Оновлення ЛР №4)

## 1. Середовище тестування
- **Клієнтський пристрій:** Фізичний смартфон / Емулятор Android (API 34+).
- **Backend-сервер:** Локальний REST API сервер (`FastAPI` + AI-компонент) за адресою `http://10.0.10.163:8000/`.
- **Локальне сховище:** `Jetpack DataStore (Preferences)` + JSON-серіалізація (`Gson`), файл `smartwrench_history.preferences_pb`.

## 3. Перевірка правил безпеки даних (Data & AI Rules)
- Використано синтетичні діагностичні коди (`P0300`, `P0113`, `P0420`, `P0421`) та тестові показники пробігу (`12369`, `852698`, `258965`, `25896`).
- У локальному сховищі `DataStore` не зберігаються API-ключі, токени або технічні стек-трейси помилок.
- Кожен запит отримує унікальний `UUID` (наприклад, `69bf7789-5a08-400f-9435-61f41c015416`) і зберігається як окремий історичний запис, не підміняючи попередні результати.
