# Тестування
**Запуск Backend:** `python main.py` (доступно на http://0.0.0.0:8000)
**Сценарії ручного тестування:**
1. Коректний DTC (P0171) без пробігу -> Успіх.
2. Коректний DTC (P0171) з великим пробігом (200000) -> Успіх (змінена порада).
3. Порожній DTC -> Помилка 400.
4. Вимкнений сервер -> Додаток показує помилку зв'язку.

# Тестування мобільного застосунку SmartWrench (Оновлення ЛР №4)

## 1. Середовище тестування
- **Клієнтський пристрій:** Android-емулятор Pixel 10 (API 34 / API 37).
- **Backend-сервер:** Локальний REST API сервер (`FastAPI` + AI-компонент) за адресою `http://10.0.10.163:8000/`.
- **Локальне сховище:** `Jetpack DataStore (Preferences)` + JSON-серіалізація (`Gson`), файл `smartwrench_history.preferences_pb`.

## 3. Перевірка правил безпеки даних (Data & AI Rules)
- Під час тестування використано синтетичні коди несправностей (`P0171`, `P023`, `P0300`) та тестові значення пробігу.
- Перевірено вміст JSON-структури у `DataStore`: API-ключі, токени, мережеві заголовки та технічні стек-трейси помилок (`Exception stacktraces`) на пристрої **не зберігаються**.
- Підтверджено, що кожен новий запуск чи запит створює окремий історичний запис із власним `UUID` та часовою міткою `createdAt`, не перезаписуючи попередні результати.
