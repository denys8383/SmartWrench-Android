# SmartWrench - AI-Assisted OBD2 Car Diagnostic App

## Опис ідеї 
**SmartWrench** — це розумний мобільний додаток для автомобілістів та ентузіастів, який виводить діагностику авто на новий рівень. На відміну від стандартних сканерів, які видають лише сухі P-коди помилок, додаток пов'язує виявлену проблему з конкретною конфігурацією автомобіля (наприклад, 2.0-літровий бензиновий двигун) та надає детальну покрокову інструкцію з ремонту. 

Додаток також включає інтегрованого AI-асистента, який отримує прихований контекст несправності та допомагає користувачеві підібрати інструменти, оцінити ризики та розібратися у складностях ремонту.

**Обрана індустрія:** Автомобільна сфера.

## Основні функціональні вимоги
1. **Автоматичне підключення та зчитування даних:** Додаток встановлює з'єднання з діагностичним адаптером (на базі ELM327) для зчитування кодів несправностей з ECU. *(Примітка: в рамках поточного MVP та для демонстрації логіки розробки, модуль підключення реалізовано через Mock-об'єкт).*
2. **Управління профілем ("Мій Гараж"):** Створення, редагування та збереження профілю автомобіля (марка, модель, рік, об'єм та тип двигуна) для забезпечення точності інструкцій.
3. **Контекстна розшифровка помилок:** Зіставлення коду несправності (DTC) з активним профілем авто та генерація конкретної покрокової інструкції з ремонту.
4. **Інтелектуальний AI-асистент:** Вбудований чат на базі LLM, який автоматично отримує контекст помилок автомобіля для надання персоналізованих консультацій щодо ремонту.
5. **Автономність базових функцій:** Збереження історії зчитаних помилок та інструкцій для доступу в офлайн-режимі (в гаражі або на трасі без інтернету).
